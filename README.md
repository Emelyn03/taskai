TaskAI v1.0 
Descripción 
TaskAI es una aplicación móvil desarrollada en Flutter para la gestión de tareas personales 
y académicas. 
Funcionalidades 

● Crear tareas 
● Editar tareas 
● Eliminar tareas 
● Marcar tareas completadas 
● Filtrar por categoría 
● Filtrar por estado 
● Visualizar estadísticas 

Tecnologías
● Flutter 3.x 
● Dart 3.x 
● Provider 
● Material Design 3 

Instalación 
1. Clonar el repositorio. 
2. Ejecutar: 
flutter pub get 
3. Ejecutar: 
flutter run 

Generar APK 
flutter build apk --release 

build\app\outputs\flutter-apk\app-release.apk
